# House Price Prediction

## Project Overview
House Price Prediction is a Machine Learning project that predicts house prices based on relevant input features. It uses a trained prediction model and provides a simple application interface for users.

## Problem Statement
Estimating house prices manually can be difficult because property values depend on multiple factors. This project uses Machine Learning to estimate house prices based on the available dataset and input features.

## Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Streamlit

## Installation

1. Clone the repository:

```bash
git clone https://github.com/megamithra/house-price-prediction.git
```

2. Navigate to the project directory:

```bash
cd house-price-prediction
```

3. Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```

The project uses `data.csv` as its dataset for training and prediction.
